# 时刻计 · Shikeji

> 您的健康提醒助手 —— 面向久坐办公族的微信小程序，也提供 Android 原生版本。

「时刻计」帮助你规律地照顾自己的身体：定时提醒起身、喝水、远眺放松，配合 1 分钟呼吸冥想和健康分打卡，让努力工作与爱护身体并行。

## ✨ 功能特性

### 提醒卡片（首页）
- 默认内置 **起身活动 / 喝水提醒 / 远眺放松** 三个提醒，倒计时实时可见
- 倒计时结束自动弹窗 + 震动提醒，手动点击「已完成」开启下一轮
- 完成任务获得 **+10 健康分**，每日清零，连续打卡天数一目了然

### 呼吸冥想
- 三种模式：**4-7-8 助眠**、**等比呼吸（方块）**、**快速冷静**
- 呼吸圆圈随吸气 / 屏息 / 呼气节奏同步缩放，动画时长与各阶段精确匹配
- 每阶段秒数倒计时提示，完成一整节额外奖励 **+5 健康分**

### 个性化设置
- 自定义提醒的标题、描述与间隔（1-180 分钟），支持无限增删
- 设置提醒生效时间窗口，**支持跨天模式**（如 22:00 - 06:00）
- 勿扰模式：22:00 至次日 8:00 自动静默，不弹窗不打扰
- 震动提醒开关、系统级订阅消息通知（需配置模板 ID）

### 激励体系
- 今日健康分：每日从零开始，避免"躺赢"
- 连续打卡 🔥：跨天自动结算，昨天有完成则保留连续记录
- 分享卡片：一键把健康分和坚持天数分享给好友

## 🗂 项目结构

```
miniprogram/
├── app.js / app.json / app.wxss   # 小程序入口与全局配置
├── pages/
│   ├── index/      # 首页：健康分、提醒卡片、快捷入口

```

## 🚀 快速开始

### 微信小程序

1. 克隆仓库
2. 使用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 导入项目根目录
3. 填入自己的 AppID（或选择测试号）即可预览调试

### Android 版本

1. 使用 Android Studio 打开 `android/` 目录
2. 同步 Gradle 后直接运行到设备

## 🛠 技术要点

- 纯原生小程序开发，无第三方依赖
- 基于本地存储的时间锚点（`next_{id}`）实现**切走页面也不漂移**的倒计时
- 健康分逻辑收敛在 `utils/health.js`，首页与呼吸页共用同一份结算规则
- Android 端使用 WorkManager 实现后台定时提醒
